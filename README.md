# INSTALLATION:

**1. Subscribe to this mod**
**2. Launch Scrap Mechanic and press the custom game button above the creative game loader**
**3. Select this mod from the list and then load into the world and play!**

**NOTE: You do not have to manually install this mod**

# For information on importing your old raft into the new world , read the guide [here](https://steamcommunity.com/workshop/filedetails/discussion/2807590049/3391786569663862852/)!

Features:
- **A story with quests that you have to complete to unlock new parts**
- The world is a beautiful ocean to explore with new and custom tiles!
- A sharkbot that lurks beneath the water...
- New tools and weapons:
  - Axe
  - Pickaxe
  - Harpoon Gun
  - Pulling Hook
  - Fishing Rod
- New logic blocks:
  - WASD Converter
  - Water Sensor
- New parts:
  - Propeller(small and big)
  - Sail & Wind Sock
  - Farms you can PLACE down 
  - Air Tank
  - Water Purifier
  - Apiary
  - Collector to collect ocean junk
  - Creation Rotator
  - *And many more!*
- Adjusted some things:
  - Loot has been adjusted to be less grindy
  - Resources such as Component Kits can be crafted now
  - Farmbots no longer drop warehouse keys
